# Windows 實機驗收清單 — 0.2.0-rc1

交付對象：站長。請在 Windows 10／11 x64 的獨立測試使用者帳號操作，避免與原有店家資料混合。Linux 已驗證編譯、資料庫及列印模型；以下項目尚未實機執行，請逐項勾選並記錄 Windows 版本、縮放比例及結果。

## 安裝及離線啟動

- [ ] 在 PowerShell 執行 `Get-FileHash .\ExpertCar-0.2.0-rc1-win-x64.zip -Algorithm SHA256`，與 SHA256SUMS 比對。合成店家 zip 也比對。
- [ ] 完整解壓主程式到含中文與空格的路徑，例如「桌面\汽修 測試」；不是在 zip 檢視器內執行。雙擊 ExpertCar.App.exe。
- [ ] 不另外裝 .NET，以一般使用者、網路中斷的狀態能啟動；沒有缺 DLL、權限或防毒隔離錯誤。如系統提示來源，先核對雜湊與發行者，不繞過組織政策。
- [ ] 設定店名、抬頭、地址、統編、每小時工資 1000，刷卡加成勾選且填 3%，稅率 5%。關閉重開後仍保留。

## 匯入合成店家

- [ ] 解壓 synthetic-shop-demo.zip，選內部 synthetic 資料夾，核對裡面 11 個 MDB／DBF 檔案。
- [ ] 舊資料匯入 → 掃描並演練；初次空白庫預期成功 117323、跳過 0、待確認 9、失敗 0。各來源計數及待確認清單能捲動看完，演練前後首頁客戶數不變。
- [ ] 未勾選確認時不能提交；勾選「我已核對演練與待確認清單」後能提交。完成計數與演練一致，畫面提供備份位置；檔案總管能找到 backups 下匯入前備份。
- [ ] 再次演練顯示成功 0、跳過 117323、待確認 9、失敗 0；不能重複提交，待確認項目仍列示。
- [ ] F2／Enter 快查 T00-0001，只有一台，歷史工單 10 張；中文廠牌、姓名、目錄文字沒有亂碼。這些均為假資料。
- [ ] 在離線、含空格與中文路徑重做匯入演練，確定三個內附 MDBTools 都能啟動且正確讀中文。

## 開單、加修及收款

- [ ] 用 T00-0001 開新單，填診斷、維修說明、估價有效期限與今天的約定交車日期。
- [ ] 建立五行：工資 120 分鐘 × 每小時 1000；耗材 300；環保費 100；外包 500（廠商另填「合成外包廠商」）；零件 400（料號 DEMO-P1），數量均 1。儲存後關閉重開，內容仍在。
- [ ] 轉工單後加修兩項：同意零件 200（記錄同意人、面談與時間）、不同意零件 9000；各行綁定正確加修，同意項目計價，不同意項目排除。
- [ ] 開始施工 → 完工待結帳。首頁今日約定交車出現此單；改成明天則不出現在今天清單。全站工單能翻到第 2 頁，能開啟匯入舊單及新單。
- [ ] 結帳選「開發票」及「刷卡」，更新報價：折後基價 3500、稅 175、刷卡加成 110、總額 3785。取消刷卡加成時重新試算，加成列隱藏。
- [ ] 恢復啟用 3%，先收 1000，未收 2785；再收 2785，已收 3785、應收 0，兩筆付款各自保留，超收遭拒絕，付清後可完成交車。
- [ ] 重開程式後再打開此單，已收／未收及兩筆紀錄一致。

## 列印 PDF、DPI 與中文輸入

- [ ] 估價單、維修單、收據皆 A4 直式，金額均 3785；上述短測試單預期各 1 頁。抬頭、地址、統編、車主、料號、工時與廠商齊全，不同意加修有註明且不入金額。
- [ ] 三種單據各用 Microsoft Print to PDF 輸出，打開 PDF 核對頁數、金額、中文字、邊界與末頁簽名。不得把這些單據當統一發票。
- [ ] 加入超過 50 行及長中文說明後再輸出，續頁重印表頭／頁碼，無裁切、遺漏或空白末頁；簽名只在末頁。另切 A4 橫式驗證方向一致。
- [ ] 視窗寬 1440，縮放 100%、125%、150%、200% 分別看首頁、車輛履歷、工單三欄、結帳、設定、匯入與全站工單；逐區捲到底，確認按鈕／清單可達、無文字裁切。
- [ ] 注音／倉頡輸入車主、診斷、外包廠商與多行說明，候選字不被快捷鍵截斷；Tab 次序、F2、Enter、目錄篩選與快速連按正常。

## 車籍及過戶

- [ ] 編輯 VIN 12345678901234567、廠牌、車型、2022、白色後儲存，重開仍保留；VIN 少碼及錯誤年份會被拒絕。
- [ ] 先用客戶維護建立「合成新車主」。回履歷以姓名搜尋、選取新車主、填生效日並確認過戶；過戶清單可見新舊期間。
- [ ] 新開單帶入新車主；剛才已付款舊單仍是原車主，重印舊收據也不改成新車主。

若失敗，記錄操作步驟、Windows 版本、DPI、錯誤訊息及僅含假資料的畫面；勿將真實店家資料庫或客人資料放入公開回報。此清單完成前，不宣稱 Windows 實機驗收通過。

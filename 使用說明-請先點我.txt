汽修賺錢專家 ExpertCar
使用說明－請先點我

免費給汽修店使用：開估價單、轉維修工單、結帳收款，
還能用 A4 紙印出單據，交給客人確認、簽名。
資料留在店裡這台電腦，不用註冊雲端帳號。

一、下載後，先解壓縮
1. 請從 https://keelungit.com/expertcar/ 按「下載主程式」。
   「示範資料」只有假資料，裡面沒有程式；試用時才另外下載。
2. 找到下載的 zip 檔，在檔案上按滑鼠右鍵 →「全部解壓縮」。
3. 選一個好找的位置，例如 C:\ExpertCar，或桌面的 ExpertCar 資料夾。
   按「解壓縮」，等它完成。
4. 請保留整個資料夾內的檔案，不要只把程式檔拖出來，
   也不要直接在 zip 視窗裡開程式。

二、如何啟動程式？
打開剛才解壓後的 ExpertCar 資料夾，點兩下 ExpertCar.exe。
如果電腦沒有顯示 .exe，請找名稱「ExpertCar」、類型是「應用程式」的檔案。

如果跳出藍色「Windows 已保護您的電腦」：
先確認是從上面的 keelungit.com 網址下載，再照著點：
  ①「其他資訊」
  ②「仍要執行」
這是因為本軟體免費、沒有購買數位簽章，不是病毒。
如果畫面跟這裡不同，請到本文最後的聯絡入口詢問。

三、第一次使用：先用示範資料試用
1. 另外下載「示範資料」，一樣按右鍵 →「全部解壓縮」。
   裡面全是假資料，與任何真實店家無關。
2. 在程式裡選「舊資料匯入」→「選擇來源資料夾」，
   選示範資料解壓後的 synthetic 資料夾。
3. 按「掃描並演練」。這一步先看結果，還不會匯入。
   查看待確認清單，看懂後勾選「我已核對演練與待確認清單」，
   再按「備份並提交匯入」。請等畫面顯示完成。
4. 回首頁查車牌 T00-0001，查看維修履歷；試開估價單，
   加入維修項目與零件，轉工單、施工、完工，再結帳登記收款。
   也可以試印一張 A4 單據；要存檔時，印表機選 Microsoft Print to PDF。
5. 試用後，要開始使用正式資料：
   先到「店家設定」→「清空所有資料」，看清楚確認內容後再執行。
   這會清除目前的客戶、車輛、工單與收款等資料，不只是假資料。
   如果已經有店裡的真實資料，請先備份，有疑問就先聯絡我們。
   清空後，回「店家設定」填好店名、電話、地址、統編及單據抬頭，
   再開始新增或匯入自己的資料，避免假資料混入正式帳目。

四、怎麼匯入自己的舊資料？
可匯入 SuperCar（賺錢高手）資料，包含客戶、車輛、
項目／零件目錄及歷史工單等；實際可匯入內容以掃描與演練結果為準。
SuperCar、賺錢高手為其權利人之商標，本軟體與其無任何關係。

1. 關閉舊軟體，先把舊資料夾整個複製一份，保留原本那份不動。
   通常在舊軟體的安裝目錄底下，裡面會有 .MDB／.DBF 檔。
   找不到資料夾，不用自己猜，可以聯絡基隆IT協助。
2. 在 ExpertCar「舊資料匯入」→「選擇來源資料夾」，
   選剛才複製的那份，再按「掃描並演練」。
3. 核對成功、跳過、待確認與失敗清單；看不懂的先詢問。
   確認後勾選「我已核對演練與待確認清單」，
   再按「備份並提交匯入」。程式會先備份，匯入時請耐心等候。
4. 完成後查幾台熟悉的車牌，核對客戶、維修明細、金額與付款紀錄。
   舊資料的保養、驗車及保險日期，要人工核對後再啟用提醒。
   相同資料重新掃描並演練時，會跳過已匯入的資料；待確認項目仍要另外處理。
5. 正式開始前，保留原軟體與原始備份，先試開單並確認資料正確。

五、怎麼備份？
在「店家設定」→「備份資料到…」，選隨身碟或其他備份位置，
等畫面顯示完成，再確認那裡已經出現備份檔。
建議至少每週備份一次到隨身碟；搬資料、更新程式或清空前也先備份。
備份完成後把隨身碟妥善收好，別只把備份留在同一台電腦。
需要還原時請先聯絡協助，避免覆蓋目前資料。

六、聯絡方式

也可以先回產品頁：https://keelungit.com/expertcar/
請說明發生問題的步驟與畫面訊息；提供畫面前先遮住客戶姓名、電話等資料。

七、使用提醒與商標免責
這是單台 Windows 10／11 x64 電腦使用的軟體。
請勿讓多台電腦同時共用一份正在使用的資料。
本程式列印的估價單、維修單與收據不是統一發票；發票由店家另行開立。
免費軟體按現狀提供，請自行核對資料、金額及收費設定，並定期備份。
SuperCar、賺錢高手為其權利人之商標，本軟體與其無任何關係。
本軟體獨立開發，不包含對方的程式碼或真實客戶資料。

八、進階：檢查檔案（一般使用可跳過）
如需檢查下載是否完整，可請熟悉電腦的人協助比對 zip 的 SHA256。
核對值請看產品頁「進階：檢查檔案」，要對應同一個下載檔案。
這不是開啟程式前必做的步驟。
